# FINANCIA : mises à jour

Version publiée : **1.1.1** (06/11/2026).

Ce dépôt contient uniquement le code de l'application, utilisé par le bouton « Mettre à jour ».
Aucune donnée personnelle n'y figure (elles restent sur l'ordinateur de chaque utilisateur).

## Nouveautés
- Nouvelle page Devises : cours des monnaies en direct, graphique par paire et calculateur de change (avec frais)
- Vues de tableau enregistrées : colonnes, ordre et tri mémorisés d'une session à l'autre (Portefeuille, Transactions, Budget, Marchés)
- Icône Devises dans le menu et petites retouches visuelles
